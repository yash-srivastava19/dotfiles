# dotfiles

My dev environment — configs, keybindings, toolchain pins, package lists.
Managed with [chezmoi](https://chezmoi.io). Will check whether this is reprodicle on Arch/Omarchy and macOS both.
Will keep updating the dotfiles as required.

## New machine

```sh
git clone https://github.com/yash-srivastava19/dotfiles ~/dotfiles
~/dotfiles/bootstrap.sh
```

Then open a new shell and `gh auth login`.
